# 📚 1m×1m 판 폴리싱 참고 자료 (Reference)

이 폴더는 2D 판 폴리싱 경로추적 프로젝트의 근거 자료를 모아 놓은 것입니다.

## 폴더 구조

```
reference/
├── README.md                          ← 이 파일 (전체 요약)
├── 01_path_planning_papers.md         ← 경로 패턴 관련 논문/자료
├── 02_end_effector_and_pad_size.md    ← 엔드이펙터/패드 크기 관련 자료
├── 03_force_control_papers.md         ← 힘 제어 관련 논문
├── 04_trajectory_smoothing.md         ← Jerk 제한 궤적/보간 관련 논문
└── 05_industry_guides.md              ← 산업용 가이드/매뉴얼
```

## 핵심 결론 요약

| 항목 | 최적값 | 근거 |
|------|--------|------|
| 경로 패턴 | **래스터 (지그재그)** | 평판에서 가장 효율적, 균일한 커버리지 [P1-P3] |
| 패드 직경 | **150mm (6인치)** | 1m² 대면적에서 효율과 품질 균형 [E1-E3] |
| 오버랩 비율 | **30~50% (권장 40%)** | 줄무늬 방지 + 시간 효율 [G1] |
| 줄 간격 | **90mm** (150mm × 60%) | 오버랩 40% 적용 [G1] |
| 가감속 | **S-curve / Jerk 제한** | 표면 자국 방지 [T1-T3] |
| 힘 제어 | **일정 힘 5~15N** | 균일 재료 제거 [F1-F3] |
